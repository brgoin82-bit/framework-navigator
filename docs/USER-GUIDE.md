# Framework Navigator user guide

Documentation release 0.1.1 · October 26, 2026

Framework Navigator helps you locate official framework, standards and guidance resources. It contains 117 curated resource families from 44 publishers across 16 subjects. These counts describe the bundled catalog, not every framework worldwide.

1. Type a title, abbreviation or subject in Search. Try `ISO27001`, `SOC2`, `grc`, `cloud` or `credit cards`.
2. Choose a suggestion with the mouse or Up/Down and Enter. Escape dismisses suggestions.
3. Combine a subject with Publisher, Resource type, Access and Region filters. Reset clears filters. Sidebar counts describe the whole library; the result total describes your selection.
4. Move through results using page controls. Results appear 20 at a time.
5. Expand **Edition, scope & access notes**, then open the official source. Check the publisher's current edition, terms and applicability before relying on it.

Small spelling errors and partial words work, but this is heuristic search. Standard numbers are not changed to similar numbers. A related-results message means only some words matched. Zero results do not prove a resource does not exist.

**Refresh catalog** rereads the hosted JSON and preserves search/filter selections, returning to page 1. It does not research new publishers or verify editions. Owners maintain the catalog manually using [CATALOG.md](CATALOG.md).

**Dark high contrast** changes the theme. **Accent** provides presets, Hue/Saturation/Lightness sliders and a six-digit hex field. Changes are browser-local. These preferences do not change other visitors' settings or NIST Navigator.

**Copy share link** copies the current app address. A localhost address works only on the machine running the preview. Hosting access and source editing permissions are managed separately.

No account, paid API or AI service is needed. Publisher documents, certifications and assessments may have separate costs. Access labels are discovery aids, not price guarantees or legal advice.

If results seem wrong, Reset filters and try a shorter title or abbreviation. If refresh fails, keep using the loaded catalog and retry later. A missing initial catalog needs owner repair; see [OPERATIONS.md](OPERATIONS.md).
